          Driver profile

          The pattern across my repositories is the same: pick the one guarantee that matters (no oversold unit, no double charge, no unbalanced journal, no missed exit event), write the test that would catch its failure, then build until that test is green and keep it green in CI.

          I learn by building the hard version of the thing: the ledger instead of the to-do app, the race test instead of the screenshot, the state machine with all 49 transitions tested instead of a happy path.
